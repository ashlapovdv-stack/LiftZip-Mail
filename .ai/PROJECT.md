# Почта: профиль разработки

Базовая опубликованная рабочая ветка на момент установки: `codex/restore-conversation-blocks`. `main` отстаёт от неё. В другой рабочей копии есть незавершённая `codex/mail-0.5.20-compose`; не перезаписывать её изменения и не считать эту локальную ветку опубликованной.

Стек: Kotlin, Compose, AndroidView/WebView, Angus Mail; точные версии читать в Gradle выбранной ветки. Наличие `LocalStore.kt` не доказывает внедрение SQLite: сначала проверить реализацию. Профиль sqlite-migrations служит для явно порученных изменений хранения.

Для изменения кода: `bash ./gradlew --no-daemon :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug`. Для UI на подготовленном эмуляторе: `bash scripts/device-tests.sh`, предварительно прочитать скрипт этой ветки. Проверять, что версия baseline APK и проверки обновления соответствуют выпуску.

Сохранять стабильное масштабирование, скрытие панелей без перекрытия текста, положение прокрутки, компактную кнопку истории с доступным описанием, раскрытие блоков переписки и отдельный показ исходного текста. Редактор — белый независимо от темы. Текущую реализацию и ТЗ проверять до правки.

Kimi: основной workflow уже передаёт инструкцию прочитать AGENTS.md; этот файл направляет к локальному индексу навыков. В задачах явно указывать базовую ветку/SHA. Kimi не запускать Gradle и GitHub-операции; проверку выполняет интегратор/CI. Для вручную передаваемого архива включить AGENTS.md, .agents/skills и .ai, исключив секреты и реальные письма. Наличие файлов не является доказательством, что конкретный запуск модели прочитал их: в отчёте задачи указывать использованные профили и версию.
