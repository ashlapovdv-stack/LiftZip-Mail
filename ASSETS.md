# Оформление 0.5.4

Фоны созданы встроенным генератором изображений по двум предоставленным пользователем макетам. Текст, иконки, кнопки, поиск и письма отрисовывает приложение; они не включены в изображения.

- `app/src/main/res/drawable-nodpi/header_cozy.webp`: 1440×600, тёплый акварельный фон со спящим рыжим котом на ветке справа, листьями слева, светлым пустым полем для заголовка. Без текста и элементов интерфейса.
- `app/src/main/res/drawable-nodpi/header_business.webp`: 1440×600, светло-голубой рабочий стол, белая чашка кофе, ручка и угол ноутбука справа, листья слева. Без текста, логотипов и элементов интерфейса.

Промпты: «Извлечь только декоративный фон шапки из предоставленного макета, убрать весь интерфейс; широкая композиция около 2.4:1; оставить левую и центральную область светлой для нативного текста, верх справа свободным для кнопок». Для уютного варианта: «тёплая акварель, спящий рыжий кот на нижней правой ветке, кремовый фон». Для делового: «мягкая реалистичная 3D-иллюстрация, утренний свет, голубые тени, чашка, серебристый ноутбук, ручка справа, листья сверху слева».

PNG переведены в WebP для уменьшения размера APK. Фоны локальные, не зависят от почтовых серверов и не содержат пользовательских писем.
