# Отложенные улучшения

Зафиксировано 29 октября 2026 года. Применить позже, по отдельному поручению Дмитрия.

## Пересылка писем с вложениями

- Открывать редактор пересылки сразу, не ожидая подготовки всех вложений.
- Подготавливать вложения в фоне, позволяя вводить адрес и текст письма.
- Включать отправку после завершения подготовки файлов.
- Повторно использовать сохранённые файлы и убрать лишнее промежуточное копирование, сохранив надёжность черновиков.
- Подготавливать несколько файлов параллельно с ограничением нагрузки.
- Показывать прогресс подготовки каждого файла.

## Название приложения

Изменить отображаемое в Android название приложения на **«Почта»**.

## Кнопка Android «Назад» и выход из приложения

На главном экране списка писем:

1. Если боковое меню открыто, нажатие системной кнопки «Назад» закрывает меню.
2. Следующее нажатие при закрытом меню показывает подтверждение выхода из приложения.
3. Если подтверждение уже показано, ещё одно нажатие системной кнопки «Назад» выполняет выход из приложения.

## Счётчик непрочитанных в боковом меню

Рядом с переключателем каждого почтового ящика показывать числом количество его непрочитанных входящих писем. Для каждого ящика нужен отдельный счётчик.

## Сервисные сообщения внутри приложения

- Добавить смахивание всплывающих сервисных сообщений, например «Почта обновлена».
- Смахивание скрывает только карточку сообщения. Синхронизация, отправка, загрузки и другие запущенные процессы продолжают работать независимо от закрытия карточки.
- Сделать оформление аккуратнее: скруглённые края и мягкий оливково-серый фон обычных информационных сообщений в стиле приложения, с читаемым контрастом текста.
- Сообщения об ошибках должны оставаться визуально различимыми. Сохранить расположение выше системной навигации и клавиатуры.
- Детали оформления Дмитрий оставил на усмотрение разработчика.

Все изменения только записаны в план, в текущую сборку не внесены.
