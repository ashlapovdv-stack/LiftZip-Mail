# Проверка сборки 0.5.6

6 ноября 2026 года. «Почта», versionCode 18, прежняя тестовая подпись.

Автоматические проверки и сборка APK выполняются в GitHub Actions. Итоговый запуск, отчёты и контрольная сумма будут записаны после завершения проверок.

Проверяются модульные тесты, Lint, сборка приложения и Android-тестов, реальные жесты на Android 15, все три стиля с тремя кнопками и жестовой навигацией, границы списка при скрытых панелях, появление меню от целой карточки, системная кнопка «Назад», действия Спама в списке и письме, сохранение очереди при повторном открытии SQLite.

Базовый APK для проверки обновления: доставленная 0.5.5 из запуска 42058209893. Пакет и ключ подписи сохранены, схема базы не меняется.

Физический телефон Xiaomi недоступен; поведение оболочки производителя и реальные почтовые серверы проверяются пользователем после установки.
