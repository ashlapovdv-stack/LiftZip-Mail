# Проверка сборки 0.2.0

Дата: 28 октября 2026 года.

- Сборка APK и модульные тесты: ожидают выполнения через GitHub Actions. Локальная загрузка зависимостей заблокирована сетевой политикой среды.
- Выполнена предварительная проверка синтаксиса XML и баланса скобок Kotlin; это не заменяет компиляцию.
- Подготовлены проверки заголовков MIME, разбиения цитат, границ страниц IMAP, выбора отправителя, ошибок соединения и обработки имён и типов вложений, а также сохранены исходные 18 тестов.
- Android package, версия базы и тестовый ключ подписи сохранены для обновления поверх 0.1.

## Не проверено в этой среде

- Установка и интерфейс на реальном Android-устройстве или эмуляторе.
- Подключение к реальным ящикам, получение писем и отправка SMTP.
- Доставка уведомлений при заблокированном экране и режимах энергосбережения.

Для этих проверок нужны телефон и собственные тестовые ящики. Основные ограничения первой сборки перечислены в README.md.
