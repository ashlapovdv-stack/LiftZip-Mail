## Фон и системные панели

Фон вынесен из области безопасных отступов. Одна декоративная картинка охватывает строку статуса и шапку, основной цвет продолжается под системную навигацию. Список и интерактивные элементы сохраняют safeDrawingPadding. Прозрачные системные панели настраиваются общей функцией edgeMailWindow, которую использует MainActivity. Под часами добавлено мягкое осветление рисунка для читаемости значков на листьях. Системная контрастная подложка трёх кнопок отключена на API 29+; цвета значков учитывают светлую картинку, системную тему, открытое меню и переход на другие экраны.

Нативный тест использует настоящую Activity с тем же оконным конфигуратором. После изменения режима тестовый host пересоздаётся и конфигурация окна применяется как в MainActivity.onCreate. Тест переключает Android между тремя кнопками и жестами, проверяет все три стиля и делает снимки всего дисплея, включая системные панели. Проверяются цвет фона под навигацией, рисунок вместо сплошной полосы сверху, границы меню и вкладок относительно системных областей. Исходный режим навигации восстанавливается после теста. Эти проверки требуют API 30+, текущий запуск выполнен на API 35 без пропусков.

Получены полные снимки `edge-standard-buttons.png`, `edge-cozy-buttons.png`, `edge-business-buttons.png`, `edge-standard-gestures.png`, `edge-cozy-gestures.png`, `edge-business-gestures.png`. Они просмотрены вместе с существующими снимками интерфейса; всего обязательных снимков — 23.
