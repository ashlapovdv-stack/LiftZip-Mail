# Проверка сборки 0.3.2

Проверки новой версии ещё не завершены. Результаты будут записаны после GitHub Actions.

Исправлена фиксация истории только целой порцией: сначала сохраняются заголовки, затем каждый текст отдельно. Ошибка текста записывается по UID, остальные письма продолжают загружаться, повтор ограничен двумя попытками. Добавлены контроль общего времени чтения MIME и наблюдение фактического состояния WorkManager.

Точный источник остановки на телефоне на 459/600 по одному скриншоту не установлен: журналы телефона и содержимое следующего письма недоступны. Подтверждены дефекты обработки ошибок и отображения состояния в коде.

Приложение сохраняет пакет, базу и тестовую подпись. Существующие письма и настройки при обновлении не удаляются. Проверка на телефоне и реальном сервере остаётся отдельным этапом.
