## Что исправлено и проверено

1. MIME сохраняет HTML и предпочтительный обычный текст отдельно. В text/plain не попадают CSS, script, head и символы OBJ. Проверены newsletter с `@media`, HTML+plain alternative и multipart/related. CID-картинки сохраняют Content-ID, включая MIME с другим регистром, а их двоичные данные не скачиваются при разборе тела.
2. Настоящий Android WebView отображает текст рассылки и синтетический PNG. Поиск по видимому тексту находит «Аналитики», но не CSS `margin`/`important`; пиксельная проверка подтверждает, что изображение действительно нарисовано. Нажатие на ссылку передаёт точный HTTPS-адрес обработчику приложения и не переводит сам просмотрщик на внешний сайт.
3. Запрос картинки с внешнего сайта не достигает загрузчика до разрешения. После разрешения реальный WebView получает картинку через изолированную карту ресурсов. Проверяются отключённые JavaScript, DOM storage, file/content access и обычная сеть WebView.
4. Настоящий компонент MailHtmlBody с производственным загрузчиком открывает встроенный файл, расширяется до высоты содержимого и остаётся читаемым при тёмной теме приложения. Фон и цвета, явно заданные отправителем, сохраняются.
5. Числовая проверка дробных масштабов подтверждает отсутствие растущей обратной связи между высотой WebView и высотой документа. При подстройке не накапливаются пустые области.
6. HTML, версия формата и Content-ID проходят реальную запись SQLite и обновление флагов из краткого списка без потери данных. Старый JSON без этих полей читается с безопасными значениями по умолчанию. Опрос заголовков сохраняет HTML, новый формат может заменить прежний текстовый кэш. Предпросмотры не несут полное HTML-тело, а бюджет хранения учитывает обе версии.
7. Проверены удаление активного содержимого, unsafe URL и локальных URI, CID, внешние изображения, CSS background URLs, ограниченные data images, разные пространства ресурсов для разных писем и разрешений. Частные сетевые адреса отклоняются. Лимит потока останавливает большое вложение до полной записи.
8. Ссылки HTML сохраняют адрес. В обычном тексте проверены HTTP/HTTPS, www, email/mailto, литералы HTML и скобки в адресах. Предыдущая переписка остаётся свёрнутой; при неясной границе HTML показываются текущий текст и отдельная история.

Сохранены прежние проверки: настоящая инерция LazyColumn, отсутствие индикатора жеста при автоматическом обновлении, слои и короткие списки, обновление APK, миграция базы, неизменяемые файлы очереди, явное подтверждение неопределённой SMTP-доставки, два последовательных события локального TLS IMAP IDLE и быстрое завершение при отмене.

Просмотрены снимки обычных экранов и новых HTML-сценариев: `html-newsletter.png`, `html-remote.png`, `html-inline.png`. Их зелёный квадрат — специально созданный PNG для проверки загрузки и отрисовки, а не содержимое реального письма.

## Практические пределы

Проверены подготовленный MIME/HTML и синтетический PNG, настоящий движок Android и локальные файлы. Исходный EML рассылки со скриншота и реальные аккаунты Дмитрия в автоматической проверке не использовались. После установки нужно открыть исходную рассылку онлайн, показать внешние изображения и проверить её ссылки. Прежний кэш уже потерял HTML в версии 0.5.1, поэтому новое оформление запрашивается с сервера при открытии; без сети остаётся сохранённый текст.

Изображения ограничены 8 МБ и 24 млн пикселей на файл, 24 МБ на открытое письмо; распознаются растровые форматы платформы. HTTPS-загрузчик не передаёт cookie или referer письма, проверяет перенаправления и не обращается к частным/локальным IP. Файлы входят в общий кэш вложений и очищаются его обычным лимитом. Недоступный, неподдерживаемый или слишком большой рисунок получает понятную заглушку; вложение остаётся доступно отдельной карточкой, если оно есть в MIME.

Измерение времени кадров на физическом телефоне не выполнялось. Прежние внешние этапы остаются: проверка фона, уведомлений и реальных вложений на провайдерах; регистрация Google OAuth client владельцем, если нужен вход Google вместо пароля приложения. Данные для регистрации — в [GOOGLE_OAUTH_SETUP.md](GOOGLE_OAUTH_SETUP.md).
