# Проверка сборки 0.3.0

Версия приложения: 0.3.0, versionCode 3. Идентификатор ru.liftzip.mail, тестовый ключ подписи и формат базы сохранены для обновления поверх 0.1/0.2.

В этом изменении проверяются фильтрация непрочитанной почты по выбранному ящику, состояние уведомлений, планирование загрузки выбранных ящиков, восстановление позиции, редактирование параметров и границы постраничной загрузки тысяч писем.

Результаты сборки, тестов, lint и проверки подписи будут внесены после завершения GitHub Actions.

Новые экраны и работа с реальными почтовыми серверами требуют проверки на телефоне. В этом окружении учётные данные пользователя не использовались, реальные письма не отправлялись.
