# Проверка сборки 0.3.1

Изменения подготовлены к автоматической проверке. Успех сборки и число тестов будут зафиксированы после завершения GitHub Actions для этой версии.

Изменения: подписи нижних вкладок, история только в настройках, выключение ящика без удаления, независимая проверка и загрузка истории, индикатор обновления под верхней панелью.

Приложение сохраняет `ru.liftzip.mail`, базу `mail-v1.db` версии 1 и прежний ключ тестовой подписи. Новое поле `enabled` по умолчанию включено для существующих ящиков. Удалять приложение перед обновлением не требуется.

Проверка интерфейса и скорости на реальном телефоне остаётся отдельным этапом. Учётные данные пользователя и реальная отправка писем в автоматических проверках не используются.
