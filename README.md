# Почта для Android — тестовая сборка 0.5.0

Нативный почтовый клиент на Kotlin и Jetpack Compose. Несколько ящиков REG.RU, Mail.ru, Яндекса, Gmail и собственного IMAP/SMTP-сервера подключаются непосредственно с телефона. Собственный сервер приложения и размещение на хостинге не требуются.

## Установка и обновление

Установить `LiftZip-Mail-0.5.0-debug.apk` на Android 8.0 или новее **поверх прежней версии**, без удаления приложения. Сохранены package `ru.liftzip.mail` и прежняя тестовая подпись. База обновляется с версии 1 до 2 с сохранением ящиков, паролей, писем, черновиков и отправленных. Резервное копирование и перенос приватных данных Android отключены. APK предназначен для проверки, не для публикации в магазине.

Исходники и установочные файлы сохраняются в согласованной папке LiftZip-Mail на Google Диске. Код: https://github.com/ashlapovdv-stack/LiftZip-Mail. Результаты проверок и контрольные суммы: [BUILD_CHECKS.md](BUILD_CHECKS.md).

## Изменения 0.5.0

- Круговой индикатор появляется только во время ручного вытягивания списка. Автоматическая проверка и завершение обновления не вызывают его появления. Идущий процесс отмечается тонкой полосой в заранее отведённом месте.
- Панели следуют за реальным движением списка, включая инерцию после отпускания пальца. При остановке сохраняются промежуточное положение и прозрачность. Изменение размещения и графических слоёв не перестраивает верхнюю/нижнюю панель на каждом кадре. Настройка постоянного показа остаётся в «Внешнем виде».
- Боковое меню прокручивается и показывает серверные папки выбранного ящика. «Отправленные» и «Черновики» объединяют локальные и серверные копии. Папку можно загрузить полностью или приостановить её историю. Серверные UID и UIDVALIDITY учитываются отдельно для каждой папки.
- Сохранённые черновики добавляются в серверную папку Drafts, принятые SMTP-письма — в Sent. Используются устойчивые Message-ID и проверки существующей копии, чтобы повтор сохранения не отправлял письмо повторно. Старые локальные черновики и отправленные тоже попадают в синхронизацию.
- **«Исходящие и синхронизация»** в боковом меню показывает сохраняемую очередь отправки, изменений статуса и удаления. Можно повторить ошибку, открыть настройки для повторного входа, отменить ожидающее действие или вернуть неотправленное письмо в черновики. После начала SMTP отмена недоступна. Неопределённая доставка повторяется только с отдельным подтверждением.
- Вложения ожидающей отправки копируются в закрытый каталог: изменение или удаление исходного файла не меняет уже поставленное в очередь письмо. Данные очереди переживают закрытие приложения и отсутствие сети.
- **«Настройки → Хранение»**: размер кэша, предел 100/250/500/1000 МБ или без ограничения, очистка. 60% предела выделено текстам, 40% — файлам просмотра. Недавно открытые файлы могут временно превышать предел. Черновики, Исходящие, подготовленные пересылки и сохранённые пользователем файлы автоматически не очищаются. Очистка кэша не удаляет заголовки или письма с сервера.
- **«Настройки → Получение и уведомления → Быстрое получение»**: включаемый IMAP IDLE с тихим постоянным уведомлением, переподключением и резервной проверкой. Без поддержки IDLE включённый режим проверяет раз в минуту. На Android 15+ dataSync-служба имеет системный лимит шесть часов в фоне; после остановки остаётся периодический WorkManager. При открытии приложения разрешённый быстрый режим возобновляется. После принудительной остановки приложения Android требует сначала снова открыть его.
- Вход Gmail через Google AuthorizationClient, обновление токена и повторное согласие реализованы. **Регистрация этого Android-клиента в Google Cloud ещё необходима для реального входа**: [GOOGLE_OAUTH_SETUP.md](GOOGLE_OAUTH_SETUP.md). Доступен прежний вариант с паролем приложения.

## Подключение почты

При подключении проверяются защищённые IMAP и SMTP без отправки письма. Пример для почты на виртуальном хостинге REG.RU: `mail.hosting.reg.ru`, IMAP 993 TLS, SMTP 465 TLS, логин — полный email. Для другого почтового продукта брать параметры из его панели. Mail.ru и Яндексу обычно нужен отдельный пароль почтового приложения и разрешённый IMAP. Для Gmail использовать настроенный вход Google или доступный аккаунту пароль приложения. Обычный пароль Google не подходит.

Ручные параметры доступны при подключении и в настройках уже подключённого ящика. Поддерживается обязательный STARTTLS; незашифрованные соединения и отключение проверки сертификата не предлагаются. VPN и конкретная сеть могут препятствовать соединению с провайдером.

Сначала загружаются заголовки последних 100 входящих. **«Настройки → Загрузить всю историю»** запускает загрузку всех или выбранных ящиков без последовательных нажатий. Заголовки сохраняются порциями, доступные тексты — с учётом выбранного предела кэша. Каждый полученный текст сохраняется сразу. Вложения скачиваются при открытии/сохранении. Для очень большой истории можно увеличить предел или выбрать «Без ограничения». Поиск работает по загруженному содержимому.

## Сохранённые возможности

- Общие и отдельные входящие, непрочитанные выбранного ящика, избранное, черновики и отправленные.
- Различимый вид непрочитанных писем, счётчики каждого ящика, сохранение позиции списка после чтения.
- Выделение нескольких писем, изменение прочтённости и перемещение в серверную Корзину. Операции сохраняются без сети. В Корзине постоянное удаление пока не предлагается.
- Выключатель ящика без удаления данных, выбор отправителя по умолчанию, изменение отправителя в редакторе.
- Ответ, пересылка с автоматической фоновой подготовкой вложений, редактор на всю ширину. Подготовка файла не блокирует чтение другой почты.
- Просмотр изображений и PDF внутри приложения, другие форматы — через установленную программу с временным разрешением на конкретный файл. Отдельная кнопка сохраняет вложение в выбранное место.
- Распознанные прошлые ответы показаны отдельными сворачиваемыми блоками. Сохраняется доступ к исходному тексту, отсутствующие даты и отправители не выдумываются.
- Уведомления с отправителем и текстом, группировкой, разворачиванием и переходом к выбранному письму. Прочтённые уведомления убираются. Подготовка текстов идёт независимо от разрешения и смахивания уведомлений.
- Компактные сервисные карточки с округлением и смахиванием выше кнопок; закрытие карточки не отменяет процесс.
- Android «Назад»: сначала закрывается боковое меню, затем подтверждается выход. Настройки сгруппированы, служебные проверки вынесены в диагностику.
- Пароли защищены AES-GCM в Android Keystore; содержимое базы хранится в закрытом каталоге приложения. Деморежима и внешней аналитики нет.

## Практические ограничения

Проверка на эмуляторе не заменяет испытания телефона, энергосбережения конкретного производителя и собственных реальных ящиков. Уведомления требуют разрешения Android. Периодический фон WorkManager начинается от 15 минут и может задерживаться системой. IMAP IDLE также зависит от сети, доступности сервера и лимитов Android; постоянная мгновенная доставка не гарантируется.

Читается безопасная текстовая версия; HTML-скрипты, удалённые картинки и трекеры не запускаются. Файл отправки — до 20 МБ, суммарно до 25 МБ; загрузка вложения — до 25 МБ. Сервер может иметь меньший предел с учётом кодирования MIME.

При неопределённом результате SMTP проверить доставку перед ручным повтором. Подтверждённая отправка и сохранение серверной копии — отдельные действия: ошибка Sent не вызывает повтор SMTP. Старые версии черновика очищаются только безопасной адресной операцией UIDPLUS; на серверах без неё лишние старые копии могут потребовать ручной очистки. Не выполняется общее EXPUNGE чужих удалённых писем.

Черновик сохраняется кнопкой «Сохранить» или при возврате из редактора; полное автосохранение каждого нажатия при аварийном завершении процесса пока не реализовано. Смена сервера IMAP безопасно сбрасывает его старый серверный кэш; локальные черновики, отправленные и очередь остаются. Действия для прежнего сервера требуют проверки. Удаление ящика удаляет локальные данные этого ящика; письма на сервере сохраняются.

Каждый сотрудник подключает свои ящики на своём устройстве. Общей учётной записи приложения и обмена локальным кэшем между сотрудниками нет.

## Сборка и проверки

Нужны JDK 17, Android SDK 36, Build Tools 35.0.0, Google Maven и Maven Central. AGP 8.13.2, Gradle 8.13, Kotlin 2.2.21, Compose BOM 2025.12.00. Google Play services Auth 21.6.0. Стандартный публичный тестовый ключ включён для совместимых обновлений; закрытый ключ будущего релиза в исходники не добавлять.

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

GitHub Actions выполняет модульные проверки и Android 15 тесты на эмуляторе, включая реальную инерцию списка, TLS IMAP IDLE с локальным сервером, SQLite-миграцию, неизменяемые файлы очереди и обновление поверх доставленного APK 0.4.4. Пользовательские ящики и реальные получатели не используются в автоматических тестах.
